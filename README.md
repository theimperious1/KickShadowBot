You need to be serving Ollama locally in order to use this project. I use the qwen 8b model for speed here. Most queries to it are instant on my hardware (9800x3d, RTX 4080, 64gb RAM). Uses around 8gb of VRAM per message processed but thanks to setting keep_alive to 0 when querying the model, this VRAM requirement is only as long as the query takes then your VRAM should be freed up again.
